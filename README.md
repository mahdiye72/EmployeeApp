# EmployeeApp

A simple employee management application built with C# and SQL Server.

## Features

- View all employees
- Add a new employee
- Update employee salaries
- Delete employees
- Check whether an employee exists
- Calculate total salary

## Technologies

- C#
- .NET
- SQL Server
- T-SQL Stored Procedures

## Database

The application uses a SQL Server database named `CompanyDB` and an `Employees` table.

## How to Run

1. Install .NET SDK and SQL Server.
2. Create the `CompanyDB` database and the required stored procedures.
3. Configure the database connection string in the application.
4. Run the project using Visual Studio Code or the .NET CLI.
